# chestcounter-updates

Releases of a modified build of [Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter). The app checks this repository for new versions.

Only the published `ChestCounter.exe` lives here, not the source code.

Based on Fortnite-ChestCounter (MIT) and [FortniteReplayDecompressor](https://github.com/Shiqan/FortniteReplayDecompressor) (MIT): see the license files in this repository.
